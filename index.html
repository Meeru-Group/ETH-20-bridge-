TESTNET ONLY

TMR ↔ EVM Wrapped TMR

Testnet bridge interface. No mainnet assets are supported.

Connection

Wallet not connected.

TMR Testnet → wTMR

Send TMR to the bridge deposit address. After the TMR-side transaction is verified, the relayer can mint wTMR.

wTMR → TMR Testnet

Burn wTMR with the deployed testnet contract. The TMR-side relayer then processes the withdrawal.

Important: This website is only the bridge UI. A real two-way bridge still requires a TMR testnet verifier/relayer and a deployed WrappedTMR contract. Do not enter a mainnet private key or real funds.
